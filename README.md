## Featured Architectural Builds

### Flagship Platforms

### [BOURSE](https://github.com/hamidmatiny/bourse) · v1.0.0

A2A v1.0 multi-vendor agent exchange. Tagged v1.0.0, with **Phases 0–7 complete** — **871 unit + 29 DB tests** with CI green, **54 ADRs**, and a **17-service** Docker Compose stack plus **15 adversary agents**. Vendors publish Agent Cards signed with **JWS** over RFC 8785 canonical JSON, verified only against keys pinned at onboarding; card text is linted, and every agent passes a deterministic admission exam before listing. A **LangGraph** broker splits a job into subtasks and delegates each over **A2A** to the agent with the best measured reliability, cost and latency; agents built on LangGraph, **CrewAI** and plain a2a-sdk call their own **MCP** tools through a metering proxy with per-task token caps in front of local **Ollama** models. Spot checks, canaries, an egress DNS sinkhole and usage-misreport checks feed a deterministic trust engine (never an LLM); reinstating a quarantined agent needs a fresh exam plus a **Slack** approval. On a frozen 100-case test split (Wilson 95% CIs): with adversaries in the pool, **attack-caused harm 2/100 with the trust layer vs 64/100 without it**, grader pass **83/100 vs 69/100**; a 21-row attack suite was **caught 18/21 with 0/21 missed**; ablations show removing the sinkhole lets exfiltration through **9/9**. Results are generated from tracked data and CI fails on drift. Caveats published: a quiet sleeper caused **6/14** harmed tasks before a canary caught it; on an honest-only pool the broker is 15% cheaper and 18% faster than random selection but not more accurate (85/100 vs 88/100); one local model on one machine.

`A2A` · `MCP` · `Agent Trust & Security` · `LangGraph` · `CrewAI` · `JWS / RFC 8785` · `Adversarial Benchmarks` · `Ollama` · `Human-in-the-Loop`

### [FORGE](https://github.com/hamidmatiny/FORGE) · v0.2.0

Offline AV perception & auto-labeling platform. Tagged v0.2.0, with all **11 phases complete**. An 8-stage `forge` CLI pipeline runs end to end locally: ingest (nuScenes → Parquet lake) → detect2d (Faster R-CNN) and detect3d (PointNet-style) → track (SORT: Kalman + Hungarian IoU) → fuse (calibrated sensor fusion) → label (active learning / pseudo-labeling) → evaluate (BEV distance, mAP against held-out ground truth) → curate (LanceDB dedup) → visualize (rerun.io / Foxglove MCAP). A parallel cloud path (S3 → Lambda → SQS → DynamoDB → EventBridge → Step Functions → ECS Fargate → Glue → Athena, 11 tables) is Terraform-defined and CI-verified — deliberately never applied against live AWS, the same cost-safety policy as Vulcan, PRISM, and hydra-data-factory. Detection heads are documented honestly as randomly-initialized research baselines, not tuned models.

### [aegis](https://github.com/hamidmatiny/aegis) · v0.6.0

AI-native defense-in-depth gateway for LLM apps and agents. Tagged v0.6.0, with all **12 build-order stages** and a second hardening pass (stages A–D) complete — a **14-service** Docker Compose stack, **89 test files**, 4 CI workflows (ci, release, security, arm-auto-merge). A **Go** gateway routes requests through Python input-defense detectors, a **Go + CEL** policy engine, and a provider-agnostic model router, then output-defense detectors (plus an LLM judge) before any response releases; a separate agent-gate enforces tool/MCP permissions with taint tracking; every decision is **Ed25519**-signed into a Postgres audit trail. Security decisions fail closed — an outage returns `502`, never an unchecked response — documented explicitly in `FAILURE_MODES.md`. It also publishes its own adaptive red-team result rather than a vendor catch-rate demo, reporting round-1 and adaptive bypass rates separately: real-model hardening cuts round-1 bypass rate (10.8% → 9.2%), while by round 3 of an adaptive campaign **bypass rate is 72.8% → 75.0%** — reported honestly rather than smoothed over.

### [MERIDIAN](https://github.com/hamidmatiny/MERIDIAN) · v1.0.1

Multi-agent data-incident response on **LangGraph**. Tagged v1.0.1, with **Phases 0–7 complete** — **558 offline tests** with CI green on Linux, a **9-node** LangGraph state machine, and **3 MCP servers**. Sentinel runs **pandera** contracts on **Ray**; triage and root cause query read-only MCP tools (lineage, data, history), and a grounding guardrail drops any cited event the tools never returned; fix writes a patch and a regression test; a pre-critic dry run and a second-model critic review it; a deterministic verifier replays the failing partition in a sandbox; a **Slack** approval gate holds every patch for a human; a postmortem and a hash-chained Postgres audit log record the outcome. On a **72-case synthetic benchmark**: **72/72** detection, **71/72** causal accuracy, **0/27 false fixes**, **0/30** hard-mode false positives, and the verifier blocked **16/16** bad patches the LLM critic approved — **$0.00** on local **Ollama** models. Caveat: synthetic benchmark; fix attempts exhausted on 26/72 cases.

## Engineering Philosophy

> Production-quality platforms are resource-efficient and evidence-grounded by design — not bolted on after the model works. I treat serving contracts, GPU cost-safety, and observability as first-class systems problems: unify backends, schedule capacity without burning money in CI, validate data at the gate, and close the loop with metrics that survive contact with production. Success is measured by **deployment metrics** — serving reliability, GPU utilization under multi-tenant constraints, pipeline acceptance rates, and operational signal fidelity — not theoretical benchmarks that never leave the lab.
